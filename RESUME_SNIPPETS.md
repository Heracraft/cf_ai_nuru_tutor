## 🎤 Interview Talking Points

### "Tell me about this project"
```
"Nuru Tutor is an AI-powered educational platform I built for a Cloudflare assignment. 
The goal was to create a personalized tutoring experience for students learning Nuru, 
which is a Swahili-based programming language.

The interesting technical challenge was integrating multiple Cloudflare services—Workers 
for the API, Workflows for asynchronous lesson generation, and D1 for persistence—with 
Gemini AI to create a responsive, interactive learning experience.

I'm particularly proud of the architecture decision to use Cloudflare Workflows. Initially, 
lesson generation was blocking the UI for several seconds during complex AI processing. By 
moving that to an async workflow, the user gets immediate feedback while their personalized 
curriculum generates in the background."
```

### "What was the biggest challenge?"
```
"The biggest challenge was choosing between Cloudflare's Workers AI and Google's Gemini. 
Workers AI would have simplified the architecture, but during testing, I found that models 
like Llama 3.1 struggled with structured outputs and function calling—both critical for 
generating reliable lesson plans and exercises.

Gemini provided better support for these features and significantly better performance. 
I documented this decision in the README because it's an important trade-off: we're using 
an external API, but getting much more reliable results that are essential for the user 
experience."
```

### "What would you improve?"
```
"There are three main improvements I'd make:

First, add a proper ORM like Drizzle. I wrote the database migration manually in SQL, 
which worked but is brittle and error-prone as the schema evolves.

Second, enhance internationalization. I implemented basic language switching via query 
params, but a proper i18n solution would provide better UX and maintainability.

Third, add automated testing. The project has good structure for it, but I prioritized 
getting the core features working within the assignment timeline. I'd add unit tests for 
the AI prompt engineering logic and integration tests for the workflow system."
```
